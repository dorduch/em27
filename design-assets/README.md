# EM27 design assets · Revision 3

Revised against the supplied Championship Manager 01/02 screenshot: blue navigation, purple tabs, red contextual title bars, yellow numeric tables and an original office backdrop.

Start with **index.html** for the interactive prototype or **gallery.html** for the screen exports. Files run directly in a modern browser; no installation or external dependencies required. A local web server can also serve this folder.

- `index.html`, `styles.css`, `prototype.js`, `career.js`: interactive, mobile-first screen design and UI kit.
- `gallery.html`: light/dark designs with links to the PNG originals and scroll-detail views.
- `contact-sheet.html`, `screenshots/contact-sheet.png`: visual overview.
- `screenshots/`: 90 mobile screen PNGs at 390×844, plus overview/desktop previews.
- `artwork/`: original app icon SVG; 192/512px icons; maskable 512px icon; Apple 180px icon; company badge and navigation SVGs; light/dark splash SVGs and 1170×2532 PNGs.
- `tokens.json`: type, sizing, motion and semantic color tokens.
- `manifest.example.json`: PWA metadata example for implementation.
- `handoff.md`: flows, states, calendar mechanics, feedback, gameplay suggestions, implementation details and prototype limitations.

All artwork is original vector geometry. All people are fictional. Company names are accompanied by generic initials, never logos. The prototype is a design deliverable, not the production game. It saves a sample plan under `em27.design.v1`; the screen selector changes fixtures. Start a new sample game to reset. The supplied brief and DESIGN.md are not modified.

Updated brief: career ladder, stay/promotion/firing outcomes, offers, squad farewells, Reputation, company mechanics and win/loss recap sharing are covered. See `alignment.md`. Shareable sample recap PNGs are 1080×1920 in `artwork/`.
